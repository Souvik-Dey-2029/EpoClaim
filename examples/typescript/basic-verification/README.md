# EpoClaim TypeScript SDK — Basic Verification Example

This example demonstrates how to integrate the `@epoclaim/sdk` into an external Node.js/TypeScript application.

## Prerequisites

1. Node.js 18+ installed.
2. The EpoClaim FastAPI backend running at `http://localhost:8000`.

## Installation & Running

From this directory:

```bash
# Run directly with Node.js
node index.js
```

## Environment Variables

- `EPOCLAIM_BASE_URL`: URL of the EpoClaim instance (default: `http://localhost:8000`).
- `EPOCLAIM_API_KEY`: API key if authentication is enabled on the server.
